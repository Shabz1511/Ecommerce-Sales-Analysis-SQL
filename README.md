# 🛒 E-commerce Sales Analysis Using SQL

📌 Project Overview

This project focuses on analyzing e-commerce sales data using SQL. It explores customer behaviour, product performance, order status and revenue generation.

## 🛠️ Tools & Technologies

* MySQL
* SQL
* GitHub

📂 Database Tables

The project contains five tables:

1. Customers
2. Products
3. Orders
4. Order Items
5. Payments

## 📊 SQL Analysis Performed

* **Best Selling Products:** Identifies products with the highest sales quantities.
* **Cancelled Orders Count:** Calculates the total number of cancelled orders.
* **Revenue by Product:** Analyzes product-wise revenue from delivered orders.
* **Top Customers by Spend:** Identifies customers based on their total spending.

▶️ How to Run the Project

1. Install MySQL.
2. Open MySQL Workbench.
3. Execute `my_project.sql` to create the database and tables.
4. Execute `inserting_data_into_tables.sql` to insert sample data.
5. Run the individual analysis SQL files.
6. Explore the results.
